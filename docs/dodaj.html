Połącz z GitHubem – jednorazowo

Zgłoszenia trafiają do kolejki w Twoim repozytorium na GitHubie, skąd odbiera je komputer ze scraperem. Strona tworzy je sama, ale potrzebuje do tego tokenu. Token zapisuje się tylko w tej przeglądarce i jest wysyłany wyłącznie do API GitHuba.

  1. Utwórz token (fine-grained) – w Repository access wybierz Only select repositories → , w Permissions ustaw tylko Issues: Read and write.
  2. Skopiuj wygenerowany token i wklej go poniżej.

Wyszukiwanie zrobi komputer ze scraperem w ciągu kilku minut (sprawdza zgłoszenia co 5 min, dłużej, gdy akurat pobiera ceny); wyniki pojawią się poniżej.
